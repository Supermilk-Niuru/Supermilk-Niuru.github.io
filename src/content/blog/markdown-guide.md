## Markdown 语法指南

Markdown 是一种轻量级标记语言，非常适合用于博客写作。

### 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
```

### 文本样式

- **加粗** `**加粗**`
- *斜体* `*斜体*`
- ~~删除线~~ `~~删除线~~`

### 代码块

行内代码使用 `` ` `` 包裹：

```javascript
console.log('Hello World')
```

### 列表

无序列表：

- 项目 1
- 项目 2
- 项目 3

有序列表：

1. 第一步
2. 第二步
3. 第三步

### 链接和图片

```markdown
[链接文字](https://example.com)
![图片描述](图片地址)
```

### 引用

> 这是一段引用文字。
> 这是同一段引用的继续。

### 表格

| 语法 | 效果 |
|------|------|
| `**文本**` | **加粗** |
| `*文本*` | *斜体* |

以上就是 Markdown 的常用语法，掌握了这些就可以开始愉快的写作了！
